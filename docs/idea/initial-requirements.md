## アイデアメモ

### やりたいこと

暗記したい内容を「表・裏」のカード形式で登録・管理し、
ブラウザ上でめくりながら学習できるフラッシュカードアプリを作る。

### 背景・動機

資格勉強・語学・趣味の知識整理など、ジャンルを問わず使える
シンプルな暗記ツールが欲しい。
外部サービスに依存せず、ブラウザだけで完結させたい。

### 想定ユーザー

- 自分自身（センター長）
- スマートフォンでも快適に使いたい

### 使い方のイメージ

1. ブラウザでページを開く
2. カード編集画面で「表（問い）」「裏（答え）」を入力して追加
3. 学習モードでカードを1枚ずつ表示し、タップ/クリックで裏を確認
4. 次のカードへ進む
5. 全カード終了後にまとめ画面を表示
6. CSVファイルをインポートしてカードを一括登録することも可能

### 欲しい機能（優先順）

1. カードの追加・編集・削除（表・裏のテキスト入力）
2. カード一覧表示
3. 学習モード（1枚ずつ表示 → タップで裏返す → 次へ）
4. localStorageへの自動保存・読み込み
5. CSVインポート機能（ボタン押下で発動、形式：表,裏 の2列）

### 欲しくない機能（スコープ外）

- ○×による正解・不正解の記録
- スペースド・リピティション（間隔反復）アルゴリズム
- ユーザー認証・クラウド同期
- 画像・音声カード
- デッキ（カテゴリ）管理（初期スコープ外）

### 技術スタックの希望

- Vite + React
- TypeScript推奨
- CSSはCSS Modulesまたはインラインスタイル（外部UIライブラリ不使用）
- 外部ライブラリ不使用（CDN含む）
- サーバー不要（ブラウザだけで動く）

### 非機能要件

- **モバイル対応必須**：スマートフォン・タブレットでも快適に操作できること（レスポンシブデザイン）
- IEサポート不要
- localStorageにカードデータを永続保存すること
- ページリロード後もデータが維持されること

### 参考にしたいもの

- Anki（シンプルなめくり操作の参考）
- 既存のフラッシュカードアプリのUX（派手な演出は不要）

### 成功の定義

- カードを登録してめくれる状態が最速で動く
- スマホで片手操作できる
- CSVを読み込んで即学習開始できる
